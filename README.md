# IMFWAJ
I am a music producer and beat maker. I am creating a fully responsive music portfolio website with HTML5, CSS3 and vanilla JavaScript. 
**Live site**: https://arjunsrikantc09.github.io/beat-maker-portfolio-website/

# Features
- **Audio player**: Play/Pause, Previous/Next, seek bar, clickable playlist.
- **Waveform Visualizer**: Web Audio API feeds live frequency data to animated bars on a HTML5 canvas.
- **Responsive design**: Site adaptable to desktop and phones, with a hamburger menu on small screens.
- **Touch-friendly**: Hover effects apply only on devices with a mouse; buttons don’t stay stuck after taps.
- **Scroll experience**: Smooth scrolling, fade-in sections, a back-to-top button, page always reloads on top.
- **Animation**: CSS keyframe logo entrance and bouncing button.
- **Working forms**: Contact and testimonial forms sent through Formspree, with success and error messages.
- **Testimonials with proof**: Three real testimonials, each linking to a privacy-redacted screenshot of the original email.
- **Content sections**: About Me, Producer Stats, Tutoring, Social Icons, Beat Price buttons that lead to contact form (working on adding a link to buy beats directly on website).
- **SEO and sharing**: Page description, Open Graph, Twitter card tags and a custom Favicon. 
- **View source link**: the Git </> button in the nav bar and a footer link both open the GitHub repository.

# Project Structure
- index.html - page structure and content
- style.css - all styling including responsive breakpoints
- script.js - audio player, visualizer, forms, menu, scroll effects
- Audio/ - the ten tracks played by the site
- Images/ - logo, photos, testimonial screenshots
- favicon.svg - browser tab icon
